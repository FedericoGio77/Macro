# Macro exam prep

This repo is a student's prep for an introductory macroeconomics midterm.

- The user writes in Bulgarian. Answer in Bulgarian, but write the worked solutions in English (the exam language) unless asked otherwise.
- Before solving exercises, read `notes/exam_playbook.md`: it has the mock exam method, every formula from Modules 1–5 and the expected answer format.
- Head each part only with its number (1.1, 1.2, 1.3, 2.1 …). Never restate the question text: only the solution and what is asked.
- Follow the "Answer format" section of the playbook: exercise by exercise, part by part in order, exactly like the mock exam solutions, with every calculation, the graph inside the part that asks for it, and the comment where the question asks for discussion/intuition.
- Solve step by step, one part after another: formula from the course → numbers plugged in → result, then a short intuition paragraph. Use the course's notation (c0, c1, t, TR, d, i, M^d/P = f1·Y − f2·i, BD = G + TR − tY, b_t = (1+i)/(1+g)·b_{t−1} + d).
- Graphs: always draw them with `graphs/econ_style.py` (see `graphs/style_examples.py`) so they match the reference picture `graphs/examples/isoquant_isocost.png`. Render, look at the PNG, fix overlaps, then send it with SendUserFile.
- `pip install matplotlib numpy` first if matplotlib is missing.
